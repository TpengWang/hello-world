BioinforLearner

面向初学者的生物信息学入门 Workshop 设计（GitHub + Figshare/Zenodo/Dryad 资源驱动）

1) Workshop 总体结构（建议 2 天）

模块 A：Linux / Git / Conda 基础

目标：搭建可复现实验环境，学会版本管理。

模块 B：Bulk RNA-seq 分析流程

目标：从 FASTQ 到差异分析与可视化。

模块 C：单细胞 RNA-seq 入门

目标：QC、降维、聚类、注释。

模块 D：功能注释与通路富集

目标：GO / KEGG / GSEA 解读。

2) 优先参考的 GitHub 高星项目（教学主线）

说明：优先选择社区广泛使用、星标高、文档完整的项目作为教学锚点（星标会动态变化）。

Bioconductor

R/BioC生态核心

用于讲解标准化生信包生态、表达矩阵处理与统计分析。

GitHub

Snakemake

Workflow可复现

用于讲解流程编排、依赖管理与 HPC/云端扩展。

GitHub

nf-core

Best PracticePipeline

用于展示社区规范化 pipeline（如 rnaseq）。

GitHub

scverse / scanpy

Single-cellPython

单细胞分析核心工具链：AnnData + Scanpy。

GitHub

3) 数据资源模块（按引用率/影响力优先）

Zenodo（方法/流程归档）

适合沉淀 workflow 发布版本、教学数据快照和 DOI 引用。

Zenodo

Figshare（补充数据与教学材料）

适合课程手册、示例结果、附录数据共享与引用统计跟踪。

Figshare

Dryad（期刊关联数据）

适合从已发表论文反向构建“复现型”教学任务。

Dryad

4) 教学安排（示例）

  • Day 1 AM：环境安装、Linux/Git、数据下载与质控（FastQC/MultiQC）。
  • Day 1 PM：Bulk RNA-seq（比对/定量 + DESeq2 差异分析）。
  • Day 2 AM：scRNA-seq（Scanpy/Seurat 二选一）。
  • Day 2 PM：富集分析、结果可视化、可复现报告（Rmarkdown/Jupyter）。

建议学员最终提交：workflow + notebook + 可视化报告 + data DOI 链接。
